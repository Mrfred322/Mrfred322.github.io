# Shine Dental Clinic — Premium Website

Modern responsive dental clinic website with premium motion effects, glassmorphism details, interactive service cards, animated hero treatment, scroll progress, mobile navigation, WhatsApp CTA and reduced-motion accessibility support.

## Run
Open `index.html` in a browser or deploy the folder to any static hosting service.
